# Dice Log Painter（染色器）

将 SealDice 文本跑团记录去场外、按发言人染色，输出可在 Obsidian 阅读的 Markdown。支持单文件和文件夹递归处理。

版本：1.1.0 · 作者：`_yeaz_` · 许可证：[MIT](LICENSE)

## 安装

1. 解压发布包，把 `dice-log-painter` 文件夹放入笔记库的 `.obsidian/plugins/`。
2. 确认 `main.js` 和 `manifest.json` 直接位于该文件夹内，没有多嵌套一层目录。
3. 重启 Obsidian，在「设置 → 第三方插件」启用 Dice Log Painter。

插件无需编译或安装运行依赖。清单声明最低 Obsidian 版本为 0.15.0；未逐个验证历史版本与移动端。

## 使用

打开 SealDice 导出的 `.txt` 文件，执行命令「染色渲染为 Markdown」，或在文件树中右键该文件。输出为同目录同名 `.md`；已有文件须确认后才覆盖。

批量处理时执行「染色渲染整个文件夹（批量）」，或右键文件夹。插件递归处理其中的 `.txt`，确认一次后写出结果，覆盖已有同名 Markdown。

第一次处理某个目录时，会根据该目录的日志生成 `染色映射.md`。在表格中填写角色名和可选颜色，再运行染色即可：

| 昵称 | 名字 | 颜色 |
|---|---|---|
| 示例玩家 | 示例角色 | #496ca8 |

此表仅为虚构示例。颜色接受 `#RGB` 或 `#RRGGBB`；无效颜色使用自动色。留空的名字使用原昵称。映射表按目录分别读取。

## 处理规则

- 发言头采用 `昵称(账号ID) 日期 时间` 或省略日期的形式；兼容数字 ID 和 `QQ:` 等平台前缀。
- 整条消息以 `.`、`。`、`/` 开头时视为指令并剔除。以中英文左括号开头，且未闭合或闭合在末尾时，整条视为场外。正文中的夹注保留。
- 先清理 CQ 码、图片/表情/回复占位和 `@提及`，再判定场外；不下载或嵌入这些媒体。
- 染色优先级为骰子回显灰色、KP/GM 黑色、映射表指定色、按角色名生成的稳定自动色。骰子回显按文本特征识别，可能误判。
- 连续同名、同色的发言合并。发言头中的账号 ID 与时间不写入正文；正文保留换行，并转义 HTML。
- Markdown 的 `source` 只记录源文件名，`generated` 记录生成日期。

KP/GM 固定黑色，适合浅色阅读背景；深色主题的对比度未适配。非标准日志可能无法识别，应保留原始 `.txt`。

## 隐私与数据

插件只读写当前笔记库，不发起网络请求，不包含统计或遥测。发布包不含实际跑团记录、个人配置或账号信息。

染色不是全文匿名化：角色名、正文以及源文件名仍可能包含个人信息；自动生成的映射表保留原昵称。公开日志或映射表前，请自行检查这些内容。Obsidian 的同步及其他插件行为不由本插件控制。

## 开发与验证

`main.js` 同时是源码和可安装入口，采用 CommonJS。使用 Node.js 18 或以上运行：

```sh
npm test
```

测试采用虚构数据和模拟 Obsidian 接口，不需要真实笔记库。自动测试不等于真实 Obsidian 界面验证。
